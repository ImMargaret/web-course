Забрать компонент

Скачивание учитывает твои изменения. SVG — статичная графика. Скрипт создаёт в Figma редактируемый компонент с вариантами и прототипом.

Как вставить в Figma

Если твой Tools поддерживает Figma Plugin API / Run JavaScript, вставь скачанный скрипт и запусти.

Универсальный способ: распакуй month-wheel-figma.zip. В Figma Desktop открой Plugins → Development → Import plugin from manifest… и выбери manifest.json. Затем запусти «Круг месяцев · 56».

В файле появятся два примера и компоненты. Скопируй экземпляр из фрейма 01 в свой макет. Для проверки движения выбери фрейм и нажми Present.

Подписи: свойства вложенной «Основы». Шрифт: стиль «Круг месяцев/Месяц». Цвет: переменная «Колесо/Цвет». Размер: инструмент Scale (K).
