# 56 — страница бронирования

Интерактивный учебный прототип страницы бронирования пространства 56 для курса HSE.
Посетитель выбирает месяц на вращающемся колесе, свободную дату и оставляет контакты.
После проверки данных открывается подтверждение с необязательным описанием события, затем — результат заявки.

## Компонент и сценарий

Основной компонент — MonthWheel, круг из 12 месяцев на SVG.
Его геометрия, плавное вращение, инерция, фиксация через 30° и взаимодействия перенесены из предоставленного month-wheel.html.
Исходный файл сохранён без изменений в reference/month-wheel.html.

1. Выбрать месяц кликом по подписи, перетаскиванием, колёсиком мыши или боковыми стрелками.
2. Выбрать свободный день в связанном календаре.
3. Ввести имя и телефон.
4. Проверить данные в диалоге, при желании описать событие.
5. Подтвердить заявку и увидеть результат. Кнопка «Новая заявка» начинает сценарий заново.

Кнопка в центре включает и останавливает автоматическое вращение.
При остановке выбранный месяц передаётся календарю.
Стрелки календаря меняют месяц и год, в том числе декабрь ↔ январь; колесо синхронизируется.
Смена месяца сбрасывает выбранный день.
Начальное состояние — сентябрь 2027, как в календаре PDF; колесо согласовано с ним.
Календарь вычисляет настоящие дни недели и количество дней, включая високосные годы.
В исходном PDF сетка сентября 2027 не соответствовала реальному календарю — в коде это исправлено.

## Деморежим

Это учебный прототип без сервера бронирования и без отправки сообщений.
Красные даты — примеры занятости, а не подтверждённое расписание пространства.
Они недоступны для выбора; прошедшие даты также отключены.
Заявка сохраняется только в localStorage текущего браузера под ключом project56.booking.v1.
Если браузер запрещает хранилище, результат всё равно показывается с соответствующим пояснением.
Повторная отправка создаёт новый результат и заменяет предыдущую локальную запись.
Форма email внизу также работает в деморежиме: сохраняет запись локально и показывает результат.

Имя, телефон и дата проверяются до подтверждения.
Есть подписи полей, видимый фокус, управление с клавиатуры, доступные сообщения об ошибках,
нативный модальный диалог и поддержка prefers-reduced-motion.
Круг управляется стрелками, Home, End и пробелом; Enter/пробел на месяце выбирают его.
В календаре стрелки перемещают фокус между доступными датами.

## Оформление и источники

Для живого текста использованы Arial/Helvetica и Times New Roman/Georgia.
Для полного совпадения гарнитур нужны исходные файлы шрифтов и право на их использование.
У Telegram нет адреса: подпись сохранена без выдуманной ссылки.
«Залы» и «Афиша» ведут в предоставленное сообщество пространства ВКонтакте.

## React и Webpack

- React 19: компоненты и состояние сценария.
- SVG: колесо, деления, управление и графические стрелки.
- Webpack 5 + Babel: сборка JSX.
- MiniCssExtractPlugin: отдельный CSS.
- HtmlWebpackPlugin: итоговый HTML.
- Относительные пути: работа в подпапке /web-course/ на GitHub Pages.
- Все зависимости закреплены в package-lock.json.



В папке проекта:

    npm ci
    npm run dev


Проверки:

    npm test

Сборка:

    npm run build

Результат:

- docs/index.html — страница для GitHub Pages;
- docs/assets/ — JS, CSS и текст лицензии;
- docs/56-booking.html — та же React-страница в одном автономном HTML;
- docs/.nojekyll — служебный файл для статической публикации.
