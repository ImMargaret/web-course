# Проверка готового прототипа

Проверено 28 октября 2026 года.

## Сборка и автоматические проверки

- `npm test`: 5 проверок, все прошли.
- `npm run build`: production-сборка Webpack успешна.
- Сформированы `docs/index.html`, JS/CSS, `docs/.nojekyll` и автономный `docs/56-booking.html`.
- Зависимости package.json совпадают с package-lock.json.
- В автономном HTML нет внешних тегов script/src и stylesheet/link. Логотипы встроены.
- В сборке нет временных URL Figma или CDN-зависимостей.

## Проверка в браузере

Проверены разработческий вариант и минифицированный автономный HTML из production-сборки.

- Месяц на колесе меняет календарь.
- Enter на месяце выбирает его; боковая стрелка колеса выбирает следующий месяц.
- Центральная кнопка включает/останавливает вращение.
- Декабрь 2027 → следующая стрелка календаря → январь 2028.
- Пустая форма показывает ошибки даты и контактов.
- Пример занятой даты 14 сентября 2027 отключён.
- В календаре ArrowRight с 17 сентября пропускает занятую дату 18 сентября и переводит фокус на 19 сентября.
- Свободная дата → имя → телефон → диалог → описание события → подтверждение → результат.
- Возврат из диалога сохраняет заполненные поля.
- «Новая заявка» возвращает пустую форму.
- Форма email показывает явное подтверждение деморежима.
- Меню открывается и закрывается.
- Оба логотипа загружаются, имеют ненулевые размеры и находятся в своих местах.

Проверена мобильная композиция в iframe шириной 390 px и высотой 844 px
(доступная ширина документа 375 px из-за полосы прокрутки):
форма, нативный диалог, подтверждение, отсутствие горизонтального переполнения.
Высота мобильного диалога 683 px, он помещается в экран 844 px.
Длинный заголовок на узком экране переносится; его правый край не обрезается.
Десктоп проверен при ширине 1363 px; горизонтального переполнения нет.

## Границы проверки и незакрытые пункты

- Настоящие touch-жесты на физическом телефоне отдельно не тестировались.
- Открытие через file:// отдельно не автоматизировалось; автономная сборка проверена через локальный HTTP.
- Реальной отправки заявки нет: это деморежим, явно обозначенный в интерфейсе.
- GitHub Pages не опубликован: публикацию выполняет пользователь.
- Точная конфигурация Webpack курса не была предоставлена.
- Исходные шрифты не извлекаются из PDF; использованы системные аналоги.
